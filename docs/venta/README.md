# Documentos de venta — SGS

Material comercial del **Sistema de Gestión de Seguridad (SGS)** para la venta del sistema.

| Documento | Propósito | Público |
|---|---|---|
| `SGS-Propuesta-Comercial.docx` | Propuesta de valor / presentación comercial: qué es, beneficios, capacidades, diferenciadores, siguientes pasos. | Cliente / decisor de compra |
| `SGS-Flujo-Operativo.docx` | Flujo operativo funcional (anexo): cómo funciona paso a paso, por rol y módulo. | Cliente operativo / evaluación técnica-funcional |
| `SGS-Precios.docx` | Esquema de precios: planes SaaS, add-ons, On-Premise, comparativo y ejemplos de cuenta. | Cliente / decisor de compra |
| `SGS-Precios-Interno.docx` | **No compartir.** Precios + costos por servicio + márgenes + reglas de descuento. | Interno / equipo comercial |

## Notas
- Todos se generan como `.docx` editables. Al abrirlos en Word puede pedir **actualizar el índice** (F9).
- En la Propuesta Comercial, completar el bloque **Contacto** (`[ nombre / correo / teléfono comercial ]`).
- **Precios:** los montos (MXN, sin IVA) son lista sugerida ajustable. En el doc interno, cargar las tarifas reales de cada servicio para calcular costo por guardia y punto de equilibrio.
- Los generadores viven en el scratchpad de la sesión; si se requiere regenerarlos versionados, mover `gen_venta.js` / `gen_flujo.js` a `docs/venta/` o a `tools/`.
