**Fuente de verdad = los `.md`.** Los `.md` se mantienen al día (v1.7 · Oct 2026); los `.docx` son derivados para entregar al cliente y pueden ir atrás hasta que se regeneren.

- **Sin `.md` todavía:** `SGS-Flujo-Operativo` y `SGS-Precios-Interno` (siguen solo en `.docx`, por portar/actualizar).

## Notas
- En la Propuesta Comercial, completar el bloque **Contacto** (`[ nombre / correo / teléfono comercial ]`).
- **Precios:** los montos (MXN, sin IVA) son lista sugerida ajustable. En el doc interno, cargar las tarifas reales de cada servicio para calcular costo por guardia y punto de equilibrio.
- Al regenerar los `.docx`, hacerlo **desde los `.md`** para no volver a desincronizar.
